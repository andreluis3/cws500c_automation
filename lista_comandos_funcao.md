Controle da interface	O que a função deve fazer
Tensão (V)	Ler o valor e convertê-lo para a representação exigida pelo protocolo
Frequência inicial	Validar e converter a frequência inicial
Frequência final	Validar e converter a frequência final
TD	Validar a duração configurada
Coupling	Converter BCI, CDN ou CCC para o parâmetro reconhecido pelo gerador
Modulação	Converter a opção selecionada para o código aceito pelo equipamento
SETAR	Montar e enviar os comandos de configuração
PLAY	Enviar o comando correto para iniciar o teste
PAUSE	Enviar o comando correto para pausar
CONTINUE	Enviar o comando correto para continuar
STOP	Enviar o comando correto para interromper
